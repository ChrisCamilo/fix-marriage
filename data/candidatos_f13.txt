#
#   tarja topo ................ 15,000 -> 16,000 / 0,000

#   tarja base ................ 0% muda (segue ocultacao, defeito 2)

# O DEFEITO 2 CAIU -- 184311 bit 6, UM bit
#
# Byte 30.851 do payload (offset absoluto 184311). Destrava a fileira 54:
#
#   macrobloco de parada ....... 6600 -> 8160 (o quadro inteiro)
#   linhas que mudam ........... SO da 864 a 1079; acima disso byte a byte

#   tarja de baixo ............. 48,9 / 1,5 (lixo) -> uniforme, desvio 0,0000

# POR QUE AS VARREDURAS ANTERIORES DERAM ZERO
#
# Elas cobriam 16 bytes, [31472,31488), escolhidos em volta do ponto onde o
# modo `corta` mostra a parada. Exaustivo ate 3 bits, 341.376 combinacoes,
# zero. A resposta esta 630 bytes ANTES, no meio da fileira 54.
#
# A licao: o byte onde o decodificador PARA nao e o byte onde o fluxo quebrou.
# O `corta` localiza o fim do que da para consumir, nao a origem do dano.
#
# O QUE O JUIZ NOVO FEZ DIFERENTE
#
#   INTACTO_ATE=864   a imagem acima da linha 864 tem que ficar byte a byte
#                     identica. Exato, sem calibracao. Sozinho ja separa.
#   TARJA_DESCE=1     guiar pelo desvio da tarja, nao pela fronteira do borrao.
#                     Neste quadro os candidatos que levam a fronteira a 1080
#                     -- "sem borrao nenhum" -- tem desvio de tarja de 13 a 26:

# Com esse juiz, 1.086 de 8.008 bits reduzem o desvio da tarja mantendo a
# imagem intacta, e exatamente UM a torna uniforme.

# ============================================================================
